Hospital Performance Dashboard
A Power BI dashboard designed to provide a clear overview of hospital performance, patient activity, billing, length of stay, and other operational indicators.

Project Overview
The Hospital Performance Dashboard transforms hospital data into interactive visual insights. It is designed to help users quickly monitor key performance indicators (KPIs), explore patient-related information, and identify patterns across the available hospital data.

The dashboard was developed using Microsoft Power BI and includes interactive slicers, KPI cards, charts, and visual summaries.

Key KPIs
The dashboard highlights several important hospital performance metrics, including:

Total Patients -- The total number of patients represented in the dataset.
Total Billing -- The overall billing amount associated with the available hospital records.
Average Length of Stay -- The average number of days patients stayed in the hospital.
These KPIs provide a quick snapshot of the hospital's overall performance.

Dashboard Features
Interactive Filters
The dashboard includes interactive slicers that allow users to filter the data and explore specific segments of the hospital records.

Users can adjust the available filters to investigate performance from different perspectives.

Visualizations
The report contains multiple Power BI visuals, including:

KPI cards
Donut charts
Clustered column charts
Clustered bar charts
Interactive slicers
Supporting images and dashboard elements
These visuals are intended to make the information easier to understand and support data-driven analysis.

Tools & Technologies
Microsoft Power BI
Power Query -- for data preparation and transformation
DAX -- for calculations and analytical measures
Data Visualization -- for presenting hospital KPIs and trends
Dashboard Structure
The Power BI report contains dashboard pages focused on hospital performance analysis. The main dashboard presents high-level KPIs and visual summaries, while additional report elements provide more detailed exploration through charts and filters.

How to Use
Download or clone this project.
Open Hospital_Performance_Dashboard.pbix using Microsoft Power BI Desktop.
Wait for the report to load.
Use the available slicers and interactive visuals to explore the data.
Select data points in charts to cross-filter other visuals where supported.
Main Questions the Dashboard Can Help Explore
The dashboard can be used to investigate questions such as:

How many patients are represented in the hospital data?
What is the total billing amount?
What is the average patient length of stay?
How are hospital records distributed across the available categories?
Which categories or groups show higher or lower values?
How do the selected filters affect the hospital performance indicators?
